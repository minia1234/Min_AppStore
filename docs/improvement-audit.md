# 개선 감사 (진행 중)

- P1: 무료 동기화가 미연동 공개 저장소를 자동으로 추가해 관리자 선택을 무시했다. `scripts/sync_free.py`, `backend/src/admin-api.ts`. 명시적 연동만 허용하도록 수정했으며 로컬 테스트로 확인했다.
- P1 후보: `backend/src/admin-api.ts`의 10분 만료 잠금은 이전 실행이 살아 있으면 새 잠금을 삭제할 수 있다. 조건부 쓰기 및 실패 복구를 포함한 추가 검토가 필요하다.
- 인증: 관리자와 동기화가 `ADMIN_TOKEN`을 공유한다. 권한 분리 및 운영 전환 절차가 필요하다.
- 다운로드: `DownloadWorker.kt`는 취소를 확인하지만 부분 파일 재개와 일시정지 지원은 추가 검토 및 구현이 필요하다.
- 저장소는 현재 공개이며 README의 비공개 설명을 정정했다. 운영 설정은 변경하지 않았다.

전체 감사는 아직 완료되지 않았다.
